VAMSI AKKISETTI — RECRUITER PORTFOLIO

FILES
- index.html: portfolio homepage
- style.css: responsive styling
- script.js: mobile navigation
- Vamsi_Akkisetti_Profile.pdf: professional profile PDF

PREVIEW
Keep all files in one folder and open index.html in a browser.

PUBLISH WITH GITHUB PAGES
1. Create a public repository such as vamsi-portfolio.
2. Upload index.html, style.css, script.js, and the PDF to the repository root.
3. Open Settings -> Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Use the URL GitHub Pages displays after publishing.

IMPORTANT
Review the personal details, qualification dates, certificate details, and links before sharing.
